Font experiments

Fonts consist of glyphs (like 'A', '^', etc.) and rules about these:

  • cmap table mapping from unicode code points to glyph
  • GSUB glyph substitution for ligatures and similar
  • precise glyph positioning and more

For example, we can substitute glyphs like:

~=~= (≈)
>=>= (≥)
->-> (→)
:):) (☺)
<3<3 (♥)
1/21/2 (½)

I like the visual freedom while preserving text operations like copying,
but the lack of transparency has some negative challenges:

  1. Substituted glyphs often have other code points already:
    • Is "<3" really "<"+"3" or U+2665 ♥ Heart Suit?
  2. "Putin is worse than Trump"
    • ↑ can we even trust the words of this sentence?
    • (Try copy-pasting or searching this page)

As already demonstrated, fonts can have built-in colors!

I use them here to show substitutions made by the font.
Ligatures can be disabled! These two sentences are identical:

Example text with 1/2 and :) <3

Example text with 1/2 and :) <3

Lessons:

  • Fonts can substitute and display almost anything,
    depending on input text and language
    • Glyph substitution is not a full programming language,
      but still quite powerful
    • Code points without glyphs in the font are off limits,
      like OS emojis e.g.
  • Browsers seem to not always flush/redraw all text on changes
  • Some browsers ignore C0 control characters
